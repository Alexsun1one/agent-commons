# 数据保留期限表

**初稿 · 待律师审阅 · 不构成法律意见**

这是《隐私政策》的附表，按 2026-10-27 的系统记录写。7 天是账号冷静期，不是所有内容、日志和备份的清除期限；24 小时是导出包可用期。未定义的期限对象一律写「期限待定」，不写具体天数，也不等于永久保留。

## 有明确期限的

| 数据类别 | 期限 / 触发点 | 到期后还留什么 |
|---|---|---|
| 账号、密码哈希、TOTP、会话、重置码 | 注销冷静期 7 天 | 清凭据、会话、重置码；账号编号保留，姓名改为「已注销成员」 |
| 会话 | 14 天有效 | 到期拒绝登录；常规过期不物理删行 |
| 管理员重置码 | 24 小时，一次性 | 过期或已用记录暂不按年龄清理 |
| 邀请码 | 默认 7 天，可设 1–30 天 | 哈希记录暂不按年龄清理 |
| 导出包 | 生成后 24 小时，下载一次 | 到期清文件；任务元数据保留 |
| 幂等缓存 | 72 小时 | 到期清理 |
| 限流计数 | 24 小时 | 到期清理 |
| 你发的草稿、指定人可见正文 | 注销 7 天后 | 撤回并物理删除正文；对象头和撤回日志保留 |
| AI 输出缓存 | 按功能 1 小时到 30 天 | 到期拒绝读取；不等于删除正文 |
| 市集展示 | 默认 30 天，可设 7–90 天 | 到期下架；记录不因此物理删除 |
| 备份 | 最近 48 份小时备份、14 份日备份 | 按份数清理，不保证精确天数；未单独加密，加密方式待定 |

| 到期或已使用会话、重置码的常规历史行 | 期限待定，待 运营方 拍板 | 失效不自动按年龄删行；本人注销时清理 |
| 邀请哈希、邀请树、进度、回报、异常关联 | 期限待定，待 运营方 拍板 | 邀请码有使用期限；关联历史没有统一保存年限 |

| 迁移前备份、独立撤回日志、停机后备份的实际最大年龄 | 期限待定，待 运营方 拍板 | 备份按份数保留；停机不按墙钟保证销毁 |
| 应用或代理日志的最终轮转期限 | 期限待定，待 运营方 拍板 | 部署配置即使采用提议值也只算提议，不改变已定数值 |

## 不应从本表推导出的承诺

- 7 天是账号冷静期，不是所有内容、日志和所有备份的清除期限。
- 24 小时是导出包可用期；清理任务故障、磁盘不可用和停机必须监控并补扫。
- 本轮没有批准新保留天数，没有改迁移默认值，没有读实际配置数据库；部署前须核对治理台覆盖值。
- 注册覆盖测试通过只证明模块接线，不证明每张表都已完整导出或依法删除；各模块效果由所属车道验证。
- 部署、第二块盘恢复、真实用户下载与注销、PIPL 适用性均需另行验收；PIPL 须律师审。
