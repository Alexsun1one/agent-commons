# 隐私政策

**初稿 · 待律师审阅 · 不构成法律意见**

「智能体先锋队」（暂名）由【待填：运营主体全称】运营。这份政策说明内测期间怎么处理你的信息。生效日期【待填：生效日期】；版本规则见【待 运营方 定 S-10】。法定告知事项见【待律师确认 L-02】。〔PIPL〕标出域外和跨境段落。

## 我们收什么

- 账号：邀请码、邀请人、展示名、密码哈希、头像和简介。用于登录、显示身份、记录邀请。
- 你发的内容：讨论、回复、知识、作品、图片和 HTML、收藏、练习进度。用于按可见范围展示、备份、搜索。
- 贡献流水：来源、分值、规则版本、确认人。用于算贡献值、让你查来由。
- 登录和安全日志：时间、IP、设备、失败尝试、敏感操作。用于防撞库、查异常、处理申诉。
- 行为计量：读了多少、活跃几天。用于算等级和成长曲线，只有你同意才记。

行为计量单独同意；不同意也能用，等级改看「有用」「被采纳」。【待律师确认 L-03】

## 我们不收什么

- 不收 API key，也不收 Token 用量原始文件；只保存解析出的数字区间。
- 展示图转码去元数据；原图（含拍摄信息）只用于导出，保留到注销；不收 SVG。
- 房间内测期间不录音、不转写、不留回放。
- 群聊原始归档不上传；数据页只用审查过的匿名聚合。
- 只用登录必需的 Cookie，没有广告 Cookie。【待律师确认 L-14】

## 谁能看到

内容按可见范围展示：仅自己、受邀成员、社区成员、公开。公开本版不开放，见【待 运营方 定 S-06】。

治理 Agent 按规则初筛内容；治理员只在处理举报、申诉、安全事件时看相关内容，平时不能翻私域。应急访问要理由、期限、审批和审计；审批人见【待 运营方 定 S-08】，合法性见【待律师确认 L-07】。

贡献明细暂时只给你自己看。

## 模型和外发

〔PIPL〕未开：内测不把内容发给外部模型。

以后开模型或转写，会逐项说明用途、接收方、范围和期限并征得同意。不同意就不启用；一次勾选不覆盖未来用途。

内容不用于训练，除非你另行同意。训练默认关闭，入口见【待 运营方 定 S-15】。

## 保存多久

〔PIPL〕完整清单见《数据保留期限表》，这里只列主要项：

- 账号：存续期间；注销后 7 天冷静期，再清凭据和可变记录；这 7 天不是全部数据的清除期限；正文按附表处理，姓名改为「已注销成员」。
- 会话 14 天；导出包 24 小时；邀请码默认 7 天；幂等缓存 72 小时。
- 日志、审计、贡献流水、撤回日志、第三方投诉等：期限待定；备份留 48 份小时备份和 14 份日备份。

删除后凭据、可变记录和索引会清理；公开讨论只去标识。不把「已隔离」说成「已擦除」。

## 你的权利

〔PIPL〕导出：资料、内容、贡献流水，机器可读；【待填：天数】天内交付。

- 更正：展示名、简介、头像或归属。
- 注销：7 天冷静期，可撤回；结束后停用账号，资料按附表清理。例外见【待 运营方 定 S-07】。
- 撤回同意：停止新的行为计量；已算出的贡献记录见【待 运营方 定 S-04】。
- 申诉：按社区规则。

安全事件、争议和法定记录可能保留，见【待律师确认 L-08】。

联系：【待填：隐私联系人 / 邮箱】，【待填：天数】天内回复。

## 存储地点

〔PIPL〕存储地点待定，见【待 运营方 定 S-02】。运营方应按实际部署地点补充数据流向说明。

## 未成年人

〔PIPL〕只对 18 岁以上开放。注册时服务端要求勾选「已满 18 周岁」，只记录一条自声明审计，不收出生日期；这是声明，不是核验，详见《十八岁以上声明》。发现未满 18 岁，停用账号并按附表清理资料，见【待律师确认 L-04】。
