# 社区规则

**初稿 · 待律师审阅 · 不构成法律意见**

这些规则适用于站内讨论、知识、作品、房间和评论。内测只对 18 岁以上开放；本规则和《用户协议》《隐私政策》《十八岁以上声明》一起适用。目标是让认真做事的人敢发东西，让新人敢问问题。

## 我们希望这里是什么样

这里是一群认真做 AI 实践的人。你可以分享刚做出来的东西，也可以带着问题来。看到别人的方法，先自己试一遍，再评价。不同意就说清楚理由，对事不对人。新人问基础问题，不嘲笑；自己不懂的，不装懂。

## 不允许的事

- 骚扰和人身攻击：辱骂、威胁、跟踪、反复纠缠、拿别人的外貌或身份开玩笑。
- 泄露他人信息：住址、电话、身份证、工作单位、客户名单，包括群聊截图里的联系方式。发截图前先打码。
- 广告和刷屏：与讨论无关的拉群、卖课、返利链接，或重复刷同一句话。
- 冒充：假装别人、假装官方、假装有某个头衔或客户。
- 违法内容：法律禁止的内容，以及教唆伤害、诈骗、侵犯版权的内容。
- 未经允许的训练：拿别人的内容训练模型，或把付费、私密内容喂给外部模型。
- 刷分和互刷：互相标「有用」、互相确认、开小号刷贡献、买卖贡献值。
- 恶意 HTML：钓鱼、挖矿、偷 Cookie、外链脚本、伪装成作品的下载。

## 怎么处理

分两步。

第一步，规则层和治理 Agent 只做可逆的初筛：标成待审核、限流、要求补来源。内容不会直接消失。

第二步，删除、封禁、扣贡献值、降级，必须由治理员确认。涉及两个人的争议，用双人原则：处理的人和复核的人不是同一个。

被处理的人能看到：哪条规则、哪段内容、为什么、怎么申诉。处理记录进审计。

## 举报

所有成员都能举报，L1 也能。举报进同一个队列，权重按你的等级和历史准确率算。具体权重见【待 运营方 定 S-09】。

举报成立，加贡献值。举报不成立，只降低你的举报权重，不扣分。反复乱报，权重会降到很低，暂时不能再举报。

用举报报复别人，按骚扰处理。

## 房间规则

主持人可以：定主题、排发言顺序、邀请发言、静音、把扰乱的人移出、锁房、转交主持、结束房间。

主持人不能：替别人开麦、替别人同意录制、把房间里的私密内容搬到外面、用房间卖货或拉群。初稿按不能强制开麦写，是否技术禁止见【待 运营方 定 S-12】。

内测期间房间不录音、不转写、不留回放。以后要录音或转写，得房间里每个人都单独同意；主持人不能代同意。

## 治理 Agent 是什么

治理 Agent 是助手，不是裁判。它看新内容、举报和上传文件，给出风险等级、类别、证据片段和建议动作。

每条建议都标「Agent 建议」，不会伪装成人做的决定。它只能做可逆初筛；删除、封禁、扣分、降级要人确认。

治理台会显示 Agent 建议的采纳率和误判率。是否对全站公开见【待 运营方 定 S-13】。你可以要求人工复核。

## 申诉

对处理结果不服，在【待填：天数】天内申诉。申诉入口在处理通知里。

申诉由没参与原处理的人看；涉及规则解释或封禁的，由 L5 复核。复核期间按原处理执行，除非治理员决定暂停。

申诉结果会写明理由。有新证据可以再提。

## 规则怎么改

规则有版本号和修改记录。改之前会公告，重大改动留出讨论时间。旧版本保留，方便你查当时的规定。
